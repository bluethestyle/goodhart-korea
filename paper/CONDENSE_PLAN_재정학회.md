# 학회용 축약 설계도 — 한국재정학회(『재정학연구』 / 정기학술대회)

> 현재 정본 `main_v2.typ` ≈ **84p** (본문 ~45p + 부록 A~G ~35p + 표지/목차 ~4p)
> 목표: **A4 ~25p** (본문 ~20p + 짧은 부록 ~3p + 참고문헌 ~2p)
> 84p 친절본은 그대로 **Zenodo 풀버전(모노그래프)**으로 아카이빙 → DOI를 학회본 각주에서 1회 인용.

---

## 0. 대원칙 — "잘라내기"가 아니라 "재배치 + 문체 전환"

1. **독자 갈아타기**: 심사위원 = 경제학자/재정학자. 인과식별·정책이 그들의 언어, 위상수학·신호처리는 낯섦.
   → **앞세울 척추**: `굿하트 P-A 모형 → 12월 집행 점프 RDD 인과식별(3.42배) → 사업원형별 이질성 → 정책 처방`
   → 위상수학(TDA·PH·Mapper)·UMAP·웨이블릿은 "진짜 분석 단위(사업원형)를 **발견·검증한 도구**"로 한 문단 압축, 상세는 Zenodo.
2. **문체 역전환**: 이번에 넣은 reader-first(비유·풀이·각주·"쉽게 말해")는 *Zenodo본에만* 어울린다.
   학회본은 **간결·건조·압축** 표준 학술체로 새로 추출(잘라 붙이기 ✗).

## 4. 문체 전환 체크리스트 (친절본 → 학회본)

- [ ] 연결문 남발 정리(그래서·즉·다시 말해 과다)

## 6. 권장 워크플로

1. `main_v2.typ` 복제 → `conference_v1.typ` (또는 새 문서).
2. §1·§2·§5·§6을 위 맵대로 압축, 부록 A~G 제거(F 도출은 Zenodo).
3. 본문 그림/표를 4+4로 추림.
4. 문체 체크리스트 적용(비유·각주·스캐폴딩 제거).
5. 익명화 + Zenodo DOI 각주 삽입.
6. 컴파일 → 페이지수 확인 → 25p 맞춤 미세조정.

> 친절한 84p = Zenodo 모노그래프, 건조한 25p = 재정학회 — 두 버전이 다른 독자를 위해 공존한다. 공들인 작업은 버려지지 않는다.
