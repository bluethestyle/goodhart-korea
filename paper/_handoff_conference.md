## 작업
84페이지 학술 모노그래프(`paper/main_v2.typ`)를 **한국재정학회『재정학연구』(KCI 등재) 투고 규격**에 맞춘 축약 논문으로 만든다. 새 파일 `paper/conference_v1.typ`(초안·구조·분량·그림 배치 검증용)에 작성하되, **최종 제출본은 학회 지정 한글(HWP) 양식으로 옮겨야 함을 전제**로 한다(아래 §형식). 원본 `main_v2.typ`은 **건드리지 않는다**(그건 Zenodo 풀버전).

## ★ 두 가지 mandate

1. **재배치(repositioning), 단순 삭제 아님.** 심사위원은 경제학자·재정학자다. 척추:
   `굿하트 P-A 모형 → 12월 집행 점프 RDD 인과식별(자산취득형 3.42배) → 사업원형별 이질성 → 정책 처방`.
   위상수학(TDA·PH·Mapper)·UMAP·웨이블릿·FFT는 "진짜 분석 단위(사업원형)를 **발견·검증한 도구**"로 **한 문단** 압축, 상세는 Zenodo 보고서로.
2. **문체 역전환(친절본 → 건조한 학술체).** 원본은 reader-first(비유·풀이각주·"쉽게 말해"·"질문:/직관:" 스캐폴딩)다 — 그건 Zenodo용. **학회본은 정반대**: 간결·건조·압축. 제거할 것:
   - 비유문("쉽게 말해/비유하자면/마치 ~듯/체온계와 혈압계처럼")
   - reader-first 풀이 각주(용어는 본문 첫 등장 시 1회 괄호 정의로 충분)
   - 스캐폴딩 헤더("왜 이 검증이 먼저인가 / 질문: / 직관: / 짚을 점:")
   - 연결문 남발(그래서·즉·다시 말해)
   1문장 1주장. 자기지칭 "본 연구" 정상.

## ★ 『재정학연구』 공식 규격 (반드시 준수, 1차 출처 확인됨)

**분량**: 200자 원고지 **~180매 내외**(학회 한글 양식 기준 대략 A4 25–30쪽). → 25p보다 약간 여유 있음.

**구성 순서**: 표지(1매) → 본문 → 참고문헌 → 영문초록. 부록은 *본문 끝과 참고문헌 사이*.
- **표지**: 국문제목, **국문초록(600자 이내)**, 국문주제어(5개 내외), **JEL 분류기호**, 저자명·소속·직위·이메일. 공저 시 제1저자 명시.
- **영문초록(200단어 이내)** + 논문목차 + 핵심주제어 5 + JEL Code.
- **핵심주제어 국·영 5개 내외**, **JEL 필요**(추천: `H61` 예산제도·`H50` 정부지출·`D73` 관료제 + `D82`/`D86` 정보비대칭·계약).

**절 번호 체계**: 節 `Ⅰ,Ⅱ,Ⅲ`(14pt 진하게) > 項 `1,2,3`(12pt 진하게) > 目 `1),2),3)`(11pt). 세분화 지양. 수식은 우측정렬 `(1),(2)`.

**서식**(HWP 최종 적용 기준): 본문 11pt·줄간격 180%·들여쓰기2 / 여백 좌우 30mm·상하 15mm / 각주 9pt·130% / 국문초록 10pt·130% / 참고문헌 11pt·180%·내어쓰기3 / 영문초록 10pt·130%. (typst 초안에선 근사 적용, 정확한 스타일은 HWP 양식에서.)

**표·그림**: "본문 설명 보조 수단에 **국한**" → 그림 최소화. **본문 그림 4 / 표 4**:
- 그림: `figures/h3_umap.png`(원형4종) · `figures/h22_rdd_field.png`(or `h22_rdd_monthly.png`) · `figures/h28_evolution.png`(H6) · `figures/h14_quadrant.png`(정책 4분면)
- 표: 사업원형 예측표(원본 §3.6) · RDD 원형별 배수 · H6 원형별 변화율 · (선택) 가설×도구 매트릭스
- 번호: `<표 1>`·`<그림 1>`(장 구분 없이 일련). 표는 번호·제목·단위 **상단**, 출처·주 **하단**.

**참고문헌 양식**: 본문 인용 `(저자, 연도)`. 논문 국문「」·영문" ", 저서 국문『』·영문 *이탤릭*. **논문은 면수 필수**, DOI 권고. 배열 한글→동양→영어→서양, 가나다/ABC, 동일저자 연도순. 저자 3인 이상은 본문 "○○○ 외", 참고문헌 3인까지. (현 typst는 APA `#bibliography` — **이 양식으로 변환 필요**.)

**투고·윤리**: 온라인 `kyobo098.medone.co.kr`(Medone, 편집위원장 이동원/성균관대) + **연구윤리준수 서약서** 제출. 중복게재 금지는 "**다른 학술지**"에 한정 → Zenodo 연구보고서는 무관(안전). 저작권 이용 동의 필요.

## 페이지 예산 (목표 ~180매)

## §6 결과 감축 지침
H1(분야 무효 ΔR²=0.000+원형4종, UMAP 1그림 / TDA는 한 줄) · **H2 RDD 충실(3.42배, forest 1그림)** · H3 사이클 요약(PSD 0.332·coherence 0.54·wavelet +554% 한 표) · H4 짧게(pooled p=0.481) · H5 유지(메커니즘 규율) · H6 요약(원형별 변화율 표+COVID 단서). 확장 A/B/C·방법론 robustness → Zenodo.

## 절대 보존 핵심 수치 (값 변경·누락 금지)
- RDD: 전체 **1.91배**, 자산취득형 **3.42배**(C1 군집 풀링 n=99), 미국 Liebman-Mahoney **4.9배**
- H1: 분야 FE ΔR²=**0.000**, 원형×Δamp ΔR²=**+0.025**(R² 0.014→0.038)
- 원형 4종: 인건비형 C0(n=129)·자산취득형 C1(n=99)·출연금형 C2(n=154)·정상사업 C3(n=1,175). 활동 **1,557건**, 11년(2015–2025), 결과변수 **14분야**
- H3: PSD **0.332**, phase coherence **0.54**, wavelet **+554%**(정밀 +553.5%); H6 변화율 자산취득 +174.1%·정상 +314.3%·인건비 −1.4%
- H4: pooled p=**0.481**; 농림수산 Sobel z=**−2.897**(부트스트랩 미확증)
- H5: 사회복지 r=**−0.86**(CPI 통제), 1차차분 r=−0.762(p=0.035), Bonferroni 0.05/14=0.0036(미달→메커니즘 부재로 기각)
