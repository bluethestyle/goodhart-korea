# 수식 입력 가이드 (HWP 수식편집기)

## 사용법
한글에서 수식 위치(본문의 【별행수식 (1)~(7)】 또는 inline 변수)에 커서를 두고
**[입력] > [개체] > [수식]** (단축키 **Ctrl + N, M**)을 연다.
수식 편집기 하단 **명령 입력 줄**에 아래 'HWP 스크립트'를 그대로 **붙여넣으면** 수식으로 렌더된다.
(키보드로 그대로 타이핑해도 동일하다.)

- 스크립트가 안 풀리면 `equations/Mk.png` 이미지를 [입력]>[그림]으로 대체 삽입한다(안전망).
- 문법 요약: 아래첨자 `_`, 위첨자 `^`, 분수 `over`, 그리스 `theta`·`phi`·`alpha`·`DELTA`,
  편미분 `partial`(∂), 근사 `approx`(≈), 공백 `~`. **여러 글자 묶음은 `{ }`로 감싼다.**

## 별행수식 (본문 4곳 + 부록 3곳)

> **NABO 수식 번호**: 별행 수식 7개(본문 4 + 부록 3)에는 절·항 구분 없이 우측 정렬 일련번호 **(1)~(7)**을 매긴다(선 없음). 한글에서는 수식을 별행 가운데에 두고, 같은 줄 오른쪽 끝에 `(N)`을 우측 정렬로 표기한다. (렌더 이미지 파일 `M1~M7.png`가 수식 (1)~(7)에 대응.)

### 【(1)】 주인(정부)의 목적함수 — Ⅱ.1
의미: 주인 효용 = 기대 사회결과 − 예산의 재정비용.
```
U_P = E[Y(e_q, e_t)] - C(I)
```
이미지: `equations/M1.png`

### 【(2)】 대리인(부처·기관)의 목적함수 — Ⅱ.1
의미: 대리인 효용 = 시점가중×시점노력 + 품질가중×(측정된)품질노력 − 노력비용.
```
U_A = w_t e_t + w_q {tilde e}_q - c(e_t, e_q ; theta)
```
이미지: `equations/M2.png`
메모: `{tilde e}_q` = e 위에 물결(ẽ)을 얹고 아래첨자 q. `theta` = θ.

### 【(3)】 1차 조건(FOC) — Ⅱ.2
의미: 각 노력의 최적은 "평가 보상 = 한계비용". 품질 쪽에는 측정누설 φ′가 곱해진다.
```
w_t = {partial c} over {partial e_t} ,~~ w_q phi'(e_q) = {partial c} over {partial e_q}
```
이미지: `equations/M3.png`
메모: `~~` 는 공백 두 칸. `phi'` = φ′(프라임). 분수는 `{분자} over {분모}`.

### 【(4)】 비교정역학 부호 — Ⅱ.2
의미: 시점평가↑→게임화↑, 품질평가↑→게임화↓, 시점조정 한계비용↑→게임화↓.
```
{partial e_t^*} over {partial w_t} > 0 ,~~ {partial e_t^*} over {partial w_q} < 0 ,~~ {partial e_t^*} over {partial c_{tt}} < 0
```
이미지: `equations/M4.png`
메모: `e_t^*` = e에 아래첨자 t·위첨자 *. `c_{tt}` = c에 아래첨자 tt.

### 【(5)】 헤세 선형 시스템 — 부록
의미: 1차 조건 (3)을 w_t로 음함수 미분해 얻은 2×2 선형 시스템(헤세 행렬 × 비교정역학 벡터 = 단위 벡터).
```
LEFT [ matrix{ c_{tt} & c_{tq} # c_{qt} & c_{qq} - w_q phi'' } RIGHT ] LEFT [ matrix{ {partial e_t^*} over {partial w_t} # {partial e_q^*} over {partial w_t} } RIGHT ] = LEFT [ matrix{ 1 # 0 } RIGHT ]
```
이미지: `equations/M5.png`
메모: `matrix{ a & b # c & d }` = 2×2 행렬(`&` 열 구분, `#` 행 구분). `LEFT [ … RIGHT ]` = 대괄호. 열벡터는 1열짜리 `matrix{ 위 # 아래 }`. `phi''` = φ″(더블 프라임).

### 【(6)】 w_q 미분 선형 시스템 — 부록
의미: 같은 1차 조건을 w_q로 미분 — 좌변 헤세 행렬은 (5)와 동일, 우변만 (0, φ′)로 바뀜.
```
LEFT [ matrix{ c_{tt} & c_{tq} # c_{qt} & c_{qq} - w_q phi'' } RIGHT ] LEFT [ matrix{ {partial e_t^*} over {partial w_q} # {partial e_q^*} over {partial w_q} } RIGHT ] = LEFT [ matrix{ 0 # phi' } RIGHT ]
```
이미지: `equations/M6.png`
메모: (5)에서 분모의 w_t를 w_q로, 우변 (1, 0)을 (0, phi')로만 바꾸면 된다 — 수식 (5)를 복사해 수정하면 빠르다.

### 【(7)】 Cramer 비교정역학 세 부호 — 부록
의미: Cramer 공식으로 얻은 세 부호 — 시점평가↑→게임화↑, 품질평가↑→게임화↓, 시점조정 한계비용↑→게임화↓.
```
{partial e_t^*} over {partial w_t} = {c_{qq} - w_q phi''} over D > 0 ,~~ {partial e_t^*} over {partial w_q} = - {c_{tq} phi'} over D < 0 ,~~ {partial e_t^*} over {partial c_{tt}} < 0
```
이미지: `equations/M7.png`
메모: `D` = 헤세 행렬식(부록 본문 정의). `~~` = 공백 두 칸. 세 식을 한 줄에 쉼표로 늘어놓는다.

## 본문 inline 변수 치트시트
본문 흐름에 박힌 기호. 한글에서 (a) 글자 '아래/위 첨자' 서식으로 간단히 처리하거나,
(b) 정확히 보이려면 수식편집기에 아래 스크립트를 넣는다.

| 본문 표기 | 뜻 | HWP 스크립트 |
|---|---|---|
| w_t, w_q | 시점/품질 평가가중 | `w_t` , `w_q` |
| e_t, e_q | 시점조정/품질 노력 | `e_t` , `e_q` |
| e_t*, e_q* | 균형 노력 | `e_t^*` , `e_q^*` |
| ẽ_q | 측정된 품질노력 | `{tilde e}_q` |
| c_tt | 시점노력 한계비용 기울기 | `c_{tt}` |
| φ'(·) | 측정 누설(<1) | `phi'( cdot )` |
| α(θ_field) | 분야 정렬함수 | `alpha(theta_{field})` |
| ∂Y/∂e_t ≈ 0 | 시점은 결과에 무영향 | `{partial Y} over {partial e_t} approx 0` |
| ΔR² = 0.000 | 설명력 증분 | `DELTA R^2 = 0.000` |
| w_t ≫ w_q | 시점가중 압도 | `w_t >> w_q` |
| r = −0.86 | 상관계수 | `r = -0.86` |
| p < 10^(-124) | p값 | `p < 10^{-124}` |
| e^β | RDD 점프배율 | `e^{beta}` |

기호 대응: ≫ = `>>`, ≈ = `approx`, ≤ = `<=` 또는 `leq`, ≥ = `>=` 또는 `geq`,
× = `times`, · = `cdot`, → = `rightarrow`, ± = `+-`.

> 팁: 같은 변수(w_t 등)가 본문에 수십 번 나오므로, 수식 하나를 만들어 두고
> **복사–붙여넣기**하면 빠르다. 본문에서 단순 변수는 굳이 수식으로 안 만들고
> 글자 서식(아래첨자)만 줘도 무방하다 — 심사본 가독에는 충분하다.
