# 행정안전부 정부혁신실 (MOI) — 산출물 패키지

## 목적

부처 자체 점검 사이클에 *실시간 게임화 모니터링 dashboard* 도입을 위한 prototype 화면 + 운영 매뉴얼.

## 파일

- **`dashboard_mockup.png`** — Prototype dashboard 화면 (1280×800)
  - ① Q2 점검 우선 부처 4분면 (실데이터 ~50%)
  - ② sub05 극단 게임화 활동 TOP10 (수치 실데이터)
  - ③ 사업 원형별 12월 점프 RDD (실데이터 100%, H22)
  - ④ 출연금형 cycle 시간 강화 (실데이터 100%, H28 +649% peak / +554% 기간 평균)

## 운영 매뉴얼 (구상)

### 데이터 갱신 주기

| 데이터 | 갱신 주기 | 소스 |
|---|---|---|
| 월별 집행 | 월 (전월 말 기준) | 열린재정 OpenAPI VWFOEM |
| 부처 outcome | 연 1회 (3~6월 사이) | KOSIS, ECOS, GIR 등 |
| amp_12m_norm 재계산 | 월 1회 | FFT (직전 12개월 이동) |
| RDD 재추정 | 연 1회 (1월) | 직전 회계연도 11~12월 |
| Wavelet 시간 강화 | 연 1회 | H28 스크립트 |

### 사용자 권한 모델 (제안)

- **부처 자체 점검 담당관**: 본인 부처 + 본인 부처 활동만 조회
- **행안부 정부혁신실 운영자**: 전체 부처 조회 + 알람 설정
- **감사원 협력 사용자**: 전체 조회 + sub05 50건 export

### 알람 트리거 (제안)

1. 직전 12월 dec_pct가 평균 대비 +30% 이상인 활동
2. archetype × 분야 결합 새로 sub05 등급에 진입한 활동
3. 부처별 exposure_score 분기 평균이 직전년 동기 +10% 이상

## 구현 권고

- **백엔드**: DuckDB warehouse 직결 (현재 56MB git 트랙). 별도 ETL 불필요
- **프론트엔드**: Streamlit (Python 단일 스택) 또는 Plotly Dash
- **호스팅**: 정부 내부망 IDC 또는 행정안전부 클라우드 (NCloud)
- **최소 가동 구성**: Python 3.11+, DuckDB 0.9+, Streamlit 1.30+ — 단일 서버로 충분

## 보안 / 비식별

- 개별 사업 담당자 정보는 본 분석에 포함되지 않음 — 활동 단위 *집계 지표만*
- exposure_score 등 산출 지표는 *공개 가능* 수준이나, 부처 내부 분배 변화 추세는 *공개 보류 검토* 필요 (정책 협의 사항)
